> [!info] 基础概念
> 相关提炼内容见 [[io-system]]。


- 程序查询方式：CPU 和 I/O 串行工作，「踏步等待」
- 程序中断方式：CPU 和 I/O 并行工作
  - 异常和中断：故障、自陷、终止（内中断）；外部中断
  - 中断处理流程：中断请求 → 中断判优 → 中断响应 → 中断处理 → 中断返回
  - 中断向量：中断服务程序的入口地址
- DMA 方式：直接存储器访问
  - DMA 控制器接管总线，直接在主存和外设间传输数据
  - 传送方式：停止 CPU 访存、周期挪用、交替访存
  - 与中断方式区别：DMA 请求总线使用权，中断请求 CPU 处理时间
