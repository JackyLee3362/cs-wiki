# 4.3 CISC 和 RISC 的基本概念

> [!info] 基础概念
> 相关提炼内容见 [[instruction-set]]。


- CISC（Complex Instruction Set Computer）：指令数量多、寻址方式多、微程序控制器
- RISC（Reduced Instruction Set Computer）：指令数量少、Load/Store 架构、硬布线控制器、通用寄存器多、有利于流水线
