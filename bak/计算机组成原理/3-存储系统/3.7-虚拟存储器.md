# 3.7 虚拟存储器

> [!info] 基础概念
> 相关提炼内容见 [[virtual-memory]]。


- 虚拟存储器：将主存和辅存统一编址，为用户提供比实际主存大得多的地址空间
- 页式虚拟存储器：页表、快表 TLB
- 缺页处理：由操作系统完成，访问磁盘读入所缺页面
- Cache 与 TLB：Cache 由 SRAM 组成，TLB 由相联存储器/SRAM 组成
