# 3.1 存储器概述

> [!info] 基础概念
> 相关提炼内容见 [[memory]]。


## 存储器的分类

### 按在计算机中的作用（层次）

- 主存储器（RAM、ROM）、寄存器、Cache、辅助存储器

### 按存取方式

- 随机访问存储器：RAM（SRAM、DRAM）、ROM（MROM、PROM、EPROM、EEPROM、Flash）
- 串行访问存储器：顺序存取（磁带）、直接存取（硬盘）

### 按存储介质

- 半导体存储器：TTL、MOS
- 磁表面存储器：磁盘、磁带
- 磁芯存储器、光盘存储器

### 按信息可保存性

- 易失性存储器：RAM
- 非易失性存储器：ROM、磁表面、光存储器

## 存储器的性能指标

- 存储容量 = 存储字数 × 字长
- 单位成本 = 总成本 / 总容量
- 存储速度：数据传输率 = 数据宽度 / 存储周期（存取时间 Ta、存取周期 Tm、主存带宽 Bm）
