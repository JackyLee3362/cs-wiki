# 5.3 数据通路的功能和基本结构

> [!info] 基础概念
> 相关提炼内容见 [[cpu]]。


- 数据通路：数据在功能部件之间传送的路径
- 基本结构
  - CPU 内部单总线方式
  - CPU 内部三总线方式
  - 专用数据通路方式
- 功能：寄存器间数据传送、主存与 CPU 间数据传送、执行算术/逻辑运算
