## JavaScript / TypeScript

- [[eslint]] - 最流行的 JS/TS 静态检查工具，可插拔规则与自定义配置。

## Python

- [[ruff]] - 用 Rust 编写的极速 Python linter，可同时替代 flake8、isort 等。

## Java

- [[checkstyle]] - 检查 Java 代码是否符合编码规范（命名、格式、复杂度等）。

## Markdown

- [[markdownlint]] - 检查 Markdown 文件的书写规范（标题、列表、链接等）。

## Ruby

- [[rubocop]] - Ruby 社区的代码风格检查与静态分析工具。

## Go

- [[golangci-lint]] - Go 生态的一站式 lint 聚合器，集成众多 linter。

## 通用

- [[super-linter]] - GitHub Action 上支持多语言的一站式 lint 方案。
