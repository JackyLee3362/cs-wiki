# 7.3I/O 接口

> [!info] 基础概念
> 相关提炼内容见 [[io-system]]。

- I/O 接口功能：通信联络控制、地址译码、数据缓冲、信号转换、传送命令和状态
- I/O 接口类型
  - 按数据传送方式：并行接口（8255）、串行接口（8251）
  - 按控制方式：程序查询接口、中断接口（8259）、DMA 接口（8257）
  - 按可编程性：可编程接口、不可编程接口
- I/O 接口编址：统一编址、独立编址
