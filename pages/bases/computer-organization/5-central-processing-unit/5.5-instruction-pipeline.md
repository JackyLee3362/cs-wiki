> [!info] 基础概念
> 相关提炼内容见 [[instruction-pipeline]]、[[pipeline-hazard]]。


- 五级流水：取指 IF → 译码 ID → 取操作数 OF → 执行 EX → 写回 WB
- 流水线的分类：按级别、功能、工作方式、结构
- 影响因素
  - 资源冲突（结构冒险）：争用同一功能部件
  - 数据冲突（数据冒险）：RAW、WAR、WAW
  - 控制冲突（控制冒险）：主要由转移指令引起
- 性能指标
  - 吞吐率：$$TP = \frac{n}{T_k}$$，最大 $$TP_{max} = \frac{1}{\Delta t}$$
  - 加速比：$$SP = \frac{nm}{m+n-1}$$
  - 效率：各功能段利用率
- 超标量流水线、超流水线、超长指令字（VLIW）
