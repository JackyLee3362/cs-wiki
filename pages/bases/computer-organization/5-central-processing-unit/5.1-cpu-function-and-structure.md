# 5.1CPU 的功能和基本结构

> [!info] 基础概念
> 相关提炼内容见 [[cpu]]。

- CPU 功能：指令控制、操作控制、时间控制、数据加工、中断处理
- 运算器：ALU、ACC、暂存寄存器、通用寄存器组、PSW、移位器、CT
- 控制器：PC、IR、指令译码器、MAR、MDR、微操作信号发生器
- 寄存器可见性：用户可见（PC、通用寄存器、PSW）、用户不可见（MAR、MDR、IR）
