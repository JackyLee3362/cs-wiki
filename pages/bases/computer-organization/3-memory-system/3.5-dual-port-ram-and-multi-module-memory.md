> [!info] 基础概念
> 相关提炼内容见 [[memory]]。


- 双端口 RAM：两个独立端口可同时访问
- 多模块存储器
  - 单体多字存储器
  - 多体并行存储器
    - 高位交叉编址：体号 = 地址高位
    - 低位交叉编址：体号 = 地址低位，可实现流水线访问
