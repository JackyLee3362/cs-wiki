# 3.6 高速缓冲存储器 Cache

> [!info] 基础概念
> 相关提炼内容见 [[cache]]、[[locality-principle]]。


- 程序访问的局部性原理：时间局部性、空间局部性
- Cache 基本工作原理：命中率 H、效率 e = 访问 Cache 时间 / 平均访问时间
- Cache 基本结构：地址映射机构、替换机构、存储体
- 映射方式
  - 直接映射：结构简单，空间利用率低
  - 全相联映射：空间利用率高，速度慢
  - 组相联映射：折中，现代计算机常用
- 替换算法：随机、FIFO、LRU、LFU
- 写策略
  - 写直达法 Write-through：同时写 Cache 和主存
  - 写回法 Write-back：只写 Cache，替换时写回主存
