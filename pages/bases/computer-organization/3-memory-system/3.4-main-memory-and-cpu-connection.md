# 3.4 主存储器与 CPU 的连接 Main Memory

> [!info] 基础概念
> 相关提炼内容见 [[memory]]。

- 主存容量的扩展
  - 位扩展法：扩展位数，数据线单独列出
  - 字扩展法：扩展字数，片选信号选择芯片
  - 字位同时扩展法：先位扩展再字扩展
- 存储芯片的地址分配和片选：线选法、译码片选法
- 存储器和 CPU 的连接：选芯片、地址线、数据线、读写命令线、片选线
