# 2.2 定点数的表示和计算 Fixed-point Number

> [!info] 基础概念
> 相关提炼内容见 [[fixed-point]]。


- 定点数的表示
  - 有符号数和无符号数
  - 原码、补码、反码、移码
    - 原码表示法
      - 纯小数原码：$$-(1-2^{-n})\le x \le1-2^{-n}$$
      - 纯整数原码：$$-2^{n}-1\le x \le 2^{n}-1$$
      - 注意：真值零的原码有正零和负零两种形式
    - 补码表示法
      - 变形补码（模 4 补码），双符号位，00 表示正，11 表示负
    - 反码表示法
    - 移码表示法
- 定点数的运算
  - 移位运算
    - 算术移位：正数添 0；负数原码添 0，补码左移添 0 右移添 1，反码添 1
    - 逻辑移位：均添 0
    - 循环移位：带 CF 大循环与不带 CF 小循环
  - 补码加减法：$$[A+B]_补 = [A]_补 + [B]_补 \pmod M$$
  - 溢出判别：一位符号位、双符号位、根据进位判断
  - 乘法运算：原码一位乘法、补码一位乘法（Booth 算法）
  - 除法运算：原码除法（不恢复余数法）、补码除法（加减交替法）
- C 语言中的整数类型及类型转换
- 数据存储和排列：大端方式、小端方式、边界对齐
