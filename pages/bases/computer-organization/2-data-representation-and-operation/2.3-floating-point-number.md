# 2.3 浮点数的表示和运算 Floating-point Number

> [!info] 基础概念
> 相关提炼内容见 [[floating-point]]。


## 浮点数的表示

- 浮点数的表示格式：$$N=r^E\times M$$
- 规格化浮点数：最高数值位和符号位不同
  - 左规、右规
- IEEE 754 标准：$$(-1)^s\times 1.M \times2^{E-127}$$

## 浮点数的加减运算

- 对阶：小阶向大阶看齐
- 尾数求和：按定点数加减运算规则运算
- 规格化：补码规格化数符号位与数值位最高位不同
- 舍入
- 溢出判断
