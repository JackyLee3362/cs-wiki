## Astro vs Hugo

- Hugo：Go 编写，构建极快、单二进制零依赖部署；模板为 Go template，主题生态成熟，适合纯内容博客/文档站。
- Astro：JS/TS 编写，岛屿架构默认零客户端 JS；组件化可用任意前端框架，内容集合类型安全，适合内容 + 交互混合的站点。
- 结论：纯写作/文档选 Hugo，需要交互组件选 Astro。
