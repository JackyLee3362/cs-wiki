## Gogs

Gogs: 有时您想要 GitHub 体验，但托管在您自己的基础架构上。
Gogs 是一个用 Go 编写的轻量级、自托管的 Git 服务。它部署速度极快，易于部署（一个二进制文件，无任何依赖项），并且拥有与 GitHub 类似的简洁用户界面。
您可以获得用户管理、问题跟踪、SSH 支持、webhook，甚至内置 wiki。
非常适合需要私有、快速 Git 服务器而又不需要大量 GitLab 或 GitHub Enterprise 成本的小型团队或公司。

- [gogs/gogs: Gogs is a painless self-hosted Git service](https://github.com/gogs/gogs)

## ~~Glint~~

> 非开源

Glint:Git 是目前很多公司都在用的一款主流版本控制工具，对于初学者来说，Git 的使用像一个黑盒一样，执行了命令之后不知道到底发生了什么。
Glint 就是一款可以解决这项难题的工具，它是一款 Git 可视化工具，让每次提交都清晰可见，而且我们可以通过 UI 界面直接进行提交、撤销、拉取等常用操作。
