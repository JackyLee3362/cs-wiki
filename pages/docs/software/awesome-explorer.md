## DropIt

文件归类-DropIt

DropIt，一款来自国外的开源、免费软件，主打 Windows 文件自动归类，功能极其强大，只需预先设置好想要的分类规则，一键拖拽过去，接下来就是见证奇迹的时刻！这款软件并不是新出的，早在 2009 年就已发布，然而这么好用的软件却一直不红，真是可惜。至于有多好用，我们再来看一个动图。

链接：https://www.zhihu.com/question/411922752/answer/1566762726

## Files

Windows 自带的文件管理器很鸡肋，这是一个大家都感同身受。无论是外观界面，还是功能实用性，都存在很大差距，所以从这方面着手来提升 Windows 体验的工具有很多。Files 就是其中体验较好的一款。它首先在外观方面做了大量优化，简介美观，其次，它集成 Git、云存储等使用工具，支持多 tab 页，可以打标签，其中借鉴了很多 macOS 中 Finder 的优点，使得这款工具非常全面实用。

链接：https://www.zhihu.com/question/378783232/answer/3507707021

## Clover

【Clover】 是我的首选项。其实就是个壳，仅仅增加了多页签和收藏栏。
可我恰恰选择的是“仅仅”、“页签”、“收藏”，并不想给我带来太多变化，无论是操作上，还是视觉上。

## Metapath

迷你资源管理器工具

只有几百 kb 的资源管理器，绿色单文件，界面非常的简洁干净，可以给软件设置个快捷键，随时打开关闭，窗口可以置顶，每次启动显示自己设置的目录打开，非常的有意思，资源管理器该有的功能都有，喜欢猎奇的可以试试。

## Total Commander

Total Commander。
熟悉我的人都知道，我分享的软件 95%都是高效实用类；当然，Total Commander 也不例外。

Total Commander 是一款资源管理、文件操作类的效率工具，7.8M 的大小却足够强大；它拥有左右两个列表窗口，用户可以轻松将左边的文件复制、移动到右边的文件夹，反向亦可。

而且，Total Commander 左侧结构还支持标签页，就像浏览器一样，用户可以随意、轻松地切换文件夹目录，效率值爆炸。此外，Total Commander 还支持批量解压缩、批量重命名，以及丰富的快捷键操作……总之，Total Commander 是一款轻度用户很难上手、重度用户很容易上瘾的生产力工具，它就像是宝藏，要慢慢挖掘。
