## 磁盘空间分析（看空间去哪了）

| 工具                 | 特点                                           | 价格      |
| -------------------- | ---------------------------------------------- | --------- |
| **GrandPerspective** | 开源免费，矩形块状图显示文件占用               | 免费      |
| **OmniDiskSweeper**  | 免费，按文件夹大小扫描，树状展示，简单直观     | 免费      |
| **DaisyDisk**        | 彩色扇形图可视化，支持快速预览和清理，界面最美 | ¥68 左右  |
| **SpaceLens**        | 类似 DaisyDisk，支持扫描隐藏文件和系统目录     | 免费/内购 |

## 磁盘清理与维护

| 工具             | 特点                                                         | 价格           |
| ---------------- | ------------------------------------------------------------ | -------------- |
| **CleanMyMac X** | 最知名的一站式清理工具，卸载应用、清理缓存、监控健康度       | 订阅制 ~¥95/年 |
| **OnyX**         | 免费瑞士军刀，系统维护、缓存清理、参数调整，功能极多但偏极客 | 免费           |
| **AppCleaner**   | 免费，专注彻底卸载应用及其残留文件，轻量好用                 | 免费           |
| **BuhoCleaner**  | 轻量清理工具，扫描快，支持闪充清理                           | 有免费版       |

## 磁盘健康与分区管理

| 工具                             | 特点                                                 | 价格      |
| -------------------------------- | ---------------------------------------------------- | --------- |
| **Disk Utility（磁盘工具）**     | macOS 自带，分区/格式化/First Aid 修复，基础需求够用 | 免费      |
| **DriveDx**                      | 磁盘 S.M.A.R.T. 健康监测，提前预警硬盘故障           | ~¥52      |
| **Tuxera Disk Manager / Mounty** | NTFS 读写支持（需挂载 Windows 移动硬盘时有用）       | 免费/付费 |
| **iStat Menus**                  | 菜单栏实时监控磁盘读写速度、温度、剩余空间           | ~¥36      |

## 我的推荐组合

- **日常用**：DaisyDisk（看空间分布） + AppCleaner（卸载应用）+ CleanMyMac X（定期清理）
- **零成本方案**：OmniDiskSweeper（看空间） + OnyX（系统维护） + AppCleaner（卸载）
- **关注硬盘健康**：DriveDx（SSD/HDD 寿命预警）

如果你只是想快速搞清楚磁盘空间被什么占满了，**OmniDiskSweeper** 免费又够用；想追求体验和效率，**DaisyDisk + CleanMyMac X** 是最省心的组合。
