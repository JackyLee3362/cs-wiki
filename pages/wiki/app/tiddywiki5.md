## 介绍

TiddlyWiki 是一款完全开源、由 JavaScript 编写的非线性个人知识管理与网页笔记本工具。

## 核心特点

- 单文件结构：整个 Wiki（包括代码、样式和所有内容）可以被打包在一个独立的 HTML 文件中，极方便跨平台携带与备份。
- 完全开源：基于开源协议分发，代码托管于 GitHub 上的 TiddlyWiki5 仓库。
- 多运行环境：既可以直接在浏览器中以单文件运行，也可以通过 Node.js 在服务器端部署。
- 自主掌控数据：无需复杂的云端服务器架构，用户可以完全自主控制自己的隐私和数据。
