## 特点

- Rust 官方构建工具和包管理器
- 基于 crates.io 社区仓库托管依赖
- 内置编译、测试、文档生成等完整工作流
- 语义化版本管理，自动处理依赖冲突
- 跨平台支持，项目配置简洁（Cargo.toml）

## 常用命令

```sh
cargo new 项目名       # 创建新项目
cargo build            # 编译项目
cargo run              # 编译并运行
cargo test             # 运行测试
cargo add 包名         # 添加依赖
cargo doc              # 生成文档
```
