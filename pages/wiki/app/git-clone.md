## 克隆指定分支

```shell
git clone [git-repo] -b [branch-name]
# 或者
git clone -b [branch-name] [git-repo]
```

### clone 时选择 http 协议 和 ssh/git 协议 的区别

- http: 无需身份验证
- ssh: 需要 ssh 密钥
