## 定义

ICMP（Internet Control Message Protocol，网际控制报文协议）是网络层协议，用于在 IP 主机、路由器之间传递控制消息和差错报告，提高 IP 数据报交付成功的机会。

## 差错报告报文

| 类型               | 说明                               |
| :----------------- | :--------------------------------- |
| 终点不可达         | 目标网络/主机/端口不可达           |
| 源点抑制           | 路由器拥塞，要求源主机降低发送速率 |
| 时间超过           | TTL 减为 0 或分片重组超时          |
| 参数问题           | IP 首部参数错误                    |
| 改变路由（重定向） | 路由器建议更优路由                 |

## 询问报文

| 类型              | 说明             |
| :---------------- | :--------------- |
| 回显请求/回答     | ping 命令使用    |
| 时间戳请求/回答   | 用于网络时间同步 |
| 掩码地址请求/回答 | 获取子网掩码     |
| 路由器询问/通告   | 发现本地路由器   |

## 常见应用

- **ping**：测试网络连通性
- **traceroute**：追踪路由路径
