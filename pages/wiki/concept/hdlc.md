## 定义

HDLC（High-level Data Link Control，高级数据链路控制协议）是 ISO 制定的面向比特的数据链路层协议，是 PPP 的前身。

## 特点

- 面向比特（使用零比特填充法）
- 全双工通信，传输效率高
- 传输控制功能与处理功能分离，灵活性大
- 使用编号和确认机制，提供可靠传输

## 链路配置

- 非平衡配置
- 平衡配置

## 站的类型

- **主站**：控制链路操作，发送命令帧
- **从站**：受控于主站，发送响应帧
- **复合站**：既可发命令帧也可发响应帧

## 数据操作方式

- 正常响应方式 NRM
- 异步平衡方式 ABM
- 异步响应方式 ARM

## 帧类型

- **信息帧 I**：第 1 位为 0，传输数据，捎带确认
- **监督帧 S**：第 1、2 位为 10，用于流量控制和差错控制
- **无编号帧 U**：第 1、2 位为 11，用于链路建立、拆除等控制

## 与 PPP 对比

| 特性     | PPP      | HDLC         |
| -------- | -------- | ------------ |
| 面向     | 字节     | 比特         |
| 协议字段 | 有（2B） | 无           |
| 可靠传输 | 否       | 是           |
| 纠错机制 | 无       | 有编号和确认 |
