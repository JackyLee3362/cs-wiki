## 定义

子网划分（Subnetting）是将一个大的 IP 网络分割为多个 smaller 子网的技术，通过借用主机号的一部分作为子网号来实现。

## 原理

IP 地址结构：

```
{<网络号>, <子网号>, <主机号>}
```

- 子网掩码用于区分网络部分和主机部分
- 子网掩码中 1 的位数表示网络+子网部分

## 特殊 IP 地址

| 地址 | 说明 |
|:---|:---|
| 主机号全 0 | 表示网络本身 |
| 主机号全 1 | 广播地址 |
| 127.x.x.x | 环回自检地址（Loopback） |
| 0.0.0.0 | 本网络上的本主机 |
| 255.255.255.255 | 受限广播地址 |

## 计算

- 可用主机数 = $2^{主机位数} - 2$（减去网络地址和广播地址）
- 子网数 = $2^{子网位数}$
