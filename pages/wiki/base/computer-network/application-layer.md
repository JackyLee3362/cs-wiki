## 网络应用模型

### 客户/服务器模型 C/S Model

- **服务器**：被动等待请求，持续提供服务
  - 有固定 IP 地址和端口号
  - 需要处理多个并发请求
- **客户机**：主动发起请求
  - 动态 IP 地址
  - 不直接与其他客户机通信

特点：服务器中心，客户机之间通信需要通过服务器中转。

### P2P 模型（Peer-to-Peer）

- **对等方（Peer）**：既是客户机又是服务器
- 每个节点既是服务请求者也是服务提供者
- **覆盖网络（Overlay Network）**：P2P 是一种动态逻辑网络，不是独立的物理网络
- 去中心化，扩展性好

### C/S vs P2P

| 对比 | C/S | P2P |
| --- | --- | --- |
| 通信方式 | 客户机通过服务器通信 | 对等节点直接通信 |
| 可扩展性 | 服务器可能成为瓶颈 | 规模越大性能越好 |
| 数据分发 | 从服务器下载 | 多源并行下载 |
| 可靠性 | 服务器故障影响整体 | 去中心化，更健壮 |
| 文件分发时间 | 随用户数线性增长 | 通常更短 |
