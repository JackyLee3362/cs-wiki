# 域名系统 DNS

## 层次域名空间

### 顶级域名 TLD

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 国家顶级域名 | .cn、.us、.uk | 按国家和地区划分 |
| 通用顶级域名 gTLD | .com、.net、.org、.gov | 按组织性质划分 |
| 基础顶级域名 | .arpa | 用于反向域名解析 |

### 域名层次结构

从右到左层级递减：根域 → 顶级域 → 二级域 → 子域

例如：`www.example.com.` 中：
- `.` 为根域
- `.com` 为顶级域
- `example` 为二级域
- `www` 为主机名

## 域名服务器

DNS 采用层次化的分布式数据库，由以下服务器组成：

| 服务器类型 | 说明 |
| --- | --- |
| 根域名服务器 | 最高层，返回顶级域名服务器地址 |
| 顶级域名服务器 | 管理该顶级域名下的所有二级域名 |
| 授权域名服务器（权威） | 管理特定区域的域名解析，每台主机必须在此登记 |
| 本地域名服务器 | 用户直接查询的服务器，可缓存查询结果 |

## 域名解析过程

### 递归查询

主机向本地域名服务器查询，如果本地服务器不知道，它以 DNS 客户的身份继续向其他服务器查询，直到获得结果返回给主机。

主机只发送一次请求。

### 迭代查询

本地域名服务器向根域名服务器查询，根服务器返回顶级域名服务器地址；本地服务器再向顶级域名服务器查询，以此类推。

本地服务器多次向不同服务器发送请求。

### 解析流程

1. 主机向本地域名服务器查询
2. 本地域名服务器缓存中有 → 直接返回
3. 缓存中没有 → 递归或迭代查询
4. 将结果返回主机并缓存

使用传输层无连接服务（UDP，端口 53）。
