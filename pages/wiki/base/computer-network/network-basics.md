## 计算机网络的概念

计算机网络是将地理分散的、具有独立功能的多个计算机系统通过通信线路和设备互联起来，实现资源共享和信息传递的系统。

## 计算机网络的组成

- **硬件**：主机、通信链路、交换设备、传输介质
- **软件**：网络操作系统、网络协议软件、网络应用软件
- **协议**：通信规则的三要素（语法、语义、同步）

## 计算机网络的分类

### 根据分布范围

| 类型 | 缩写 | 覆盖范围 |
| --- | --- | --- |
| 广域网 | WAN | 几十到几千公里 |
| 城域网 | MAN | 5-50 公里 |
| 局域网 | LAN | 1 公里以内 |
| 个人区域网 | PAN | 10 米以内 |

### 根据交换技术

- **电路交换**：建立专用通路，通信期间独占线路
- **报文交换**：存储转发，以报文为单位
- **分组交换**：将报文分割为分组，存储转发，主流方式

### 根据传输技术

- 广播式网络：共享通信信道
- 点对点网络：每对节点之间可能存在多条路径

### 其他分类维度

- 拓扑结构：总线形、星形、环形、网状
- 使用者：公用网、专用网
- 传输介质：有线（双绞线、同轴电缆、光纤）、无线（蓝牙、微波、无线电）

## 计算机网络的性能指标

| 指标 | 说明 | 公式/单位 |
| --- | --- | --- |
| 带宽 Bandwidth | 信道最高传输速率 | bit/s |
| 时延 Delay | 数据从一端到另一端所需时间 | 发送时延 = 数据帧长度/信道带宽；传播时延 = 信道长度/电磁波传播速率 |
| 时延带宽积 | 管道可容纳的比特数 | 传播时延 × 带宽 |
| 往返时延 RTT | 往返传播时延 | 2 × 传播时延 |
| 吞吐量 Throughput | 单位时间通过的数据量 | bit/s |
| 信道利用率 | 信道被使用的时间比例 | 无单位 |

## 计算机网络体系结构

### 分层结构中的基本概念

- **SDU**（Service Data Unit，服务数据单元）：为上层提供的服务数据
- **PDU**（Protocol Data Unit，协议数据单元）：对等层之间交换的数据单位
- $n\text{-PDI} + n\text{-SDU} = n\text{-PDU}$

### 协议、接口与服务

- **协议**三要素：
  - 语法：数据格式
  - 语义：操作功能
  - 同步：时序关系
- **接口**：服务访问点 SAP（Service Access Point）
- **服务**分类：
  - 面向连接 / 无连接
  - 可靠 / 不可靠
  - 有应答 / 无应答

### OSI 七层参考模型

| 层级 | 数据单位 | 核心功能 |
| --- | --- | --- |
| 应用层 Application | 报文 | 为用户提供网络服务接口 |
| 表示层 Presentation | 数据 | 数据表示转换、压缩、加密解密 |
| 会话层 Session | 数据 | 会话管理、数据同步 |
| 运输层 Transport | 报文段/数据报 | 端到端通信、流量控制、差错控制 |
| 网络层 Network | 分组 | 路由选择、分组转发、网际互连 |
| 数据链路层 Datalink | 帧 | 物理寻址、差错控制、流量控制 |
| 物理层 Physical | 比特 | 透明传输比特流 |

### TCP/IP 四层模型

| 层级 | 对应 OSI | 核心协议 |
| --- | --- | --- |
| 应用层 | 5-7 层 | HTTP, FTP, DNS, SMTP |
| 运输层 | 4 层 | TCP, UDP |
| 网际层 | 3 层 | IP, ICMP, ARP |
| 网络接口层 | 1-2 层 | 各种物理网络协议 |

### OSI 与 TCP/IP 的关键区别

- OSI 理论模型，TCP/IP 实践标准
- OSI 在网络层同时支持无连接和面向连接；TCP/IP 网络层仅无连接
- OSI 在传输层仅面向连接；TCP/IP 传输层同时支持两种

### 点到点 vs 端到端

- **点到点**（数据链路层）：相邻节点间的直接通信
- **端到端**（运输层）：源主机进程到目的主机进程的完整传输
