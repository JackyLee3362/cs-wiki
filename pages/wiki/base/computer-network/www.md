# 万维网 WWW

## 万维网的概念与组成

| 组件 | 说明 |
| --- | --- |
| URL（统一资源定位符） | 标识互联网上资源的位置和访问方法 |
| URI（统一资源标识符） | 更广泛的概念，URL 是 URI 的子集 |
| HTTP（超文本传输协议） | 客户端与服务器之间的通信协议 |
| HTML（超文本标记语言） | 网页内容的标记语言 |

## 超文本传输协议 HTTP

### 特点

- 使用 TCP 作为传输层协议（端口 80），保证可靠传输
- **无状态**：服务器不保存客户端的历史请求信息
- **无连接**：HTTP/1.0 每次请求需要建立新连接；HTTP/1.1 支持持续连接

### HTTP 请求方法

| 方法 | 说明 |
| --- | --- |
| GET | 请求获取指定资源 |
| POST | 向服务器提交数据 |
| PUT | 上传或替换资源 |
| DELETE | 删除指定资源 |
| HEAD | 获取资源的元信息（只返回首部，不返回主体） |

### HTTP 连接类型

#### 非持久连接（HTTP/1.0）

每个请求/响应对使用一个新的 TCP 连接。

#### 持久连接（HTTP/1.1）

- **非流水线**：客户端收到前一个响应后才能发送下一个请求
- **流水线**：客户端可以连续发送多个请求，无需等待响应

### Cookie

- 用于解决 HTTP 无状态问题
- **存储在客户端**（不是服务器端）
- 服务器通过 Set-Cookie 响应头设置
- 客户端在后续请求中通过 Cookie 请求头发送
