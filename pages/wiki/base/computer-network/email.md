# 电子邮件 E-Mail

## 电子邮件系统的组成

| 组件 | 说明 |
| --- | --- |
| 用户代理 UA | 用户与邮件系统的接口（如 Outlook、Foxmail） |
| 邮件服务器 | 发送和接收邮件，采用 C/S 模式 |
| 邮件发送协议 | SMTP |
| 邮件读取协议 | POP3、IMAP |

## 电子邮件格式

### 信封

包含发件人和收件人地址等信息。

### 首部

包含 From、To、Subject、Date 等字段。

### 正文

邮件的实际内容。

### MIME（多用途网际邮件扩充）

SMTP 只能传输 7 位 ASCII 文本，MIME 用于传输非文本数据：

- 定义了多种内容类型（text、image、audio、video、application）
- 使用 Base64 编码将二进制数据转换为 ASCII 文本

## 关键协议

### SMTP（简单邮件传输协议）

- 用途：发送邮件（用户代理 → 邮件服务器，邮件服务器之间）
- 端口号：25（TCP）
- 限制：只支持 7 位 ASCII 码内容
- 特点：推送协议，主动发送邮件

### POP3（邮局协议版本 3）

- 用途：接收邮件（从邮件服务器下载到用户代理）
- 端口号：110（TCP）
- 特点：拉取协议，下载后服务器上可删除邮件
- 传输明码（不安全）
- 基于 ASCII，不能直接传输二进制数据

### IMAP（互联网邮件访问协议）

- 用途：接收邮件，支持在服务器上管理邮件
- 特点：邮件保留在服务器，支持多设备同步
