# 输入输出系统 I/O System

## I/O 系统基本概念

- I/O 软件：I/O 指令、通道指令
- I/O 硬件：外部设备、接口、输入/输出设备、外存设备

## 外部设备

### 输入设备

- 键盘、鼠标、扫描仪、摄像机

### 输出设备

- 显示器：分辨率、颜色深度、刷新频率、VRAM
- 打印机：击打式（点阵式）、非击打式（激光、喷墨）

### 外存储器

- 磁盘存储器：寻道时间、传输时间、控制器延迟
- 磁盘阵列（RAID）：磁盘镜像、条带化、奇偶校验
- 光盘存储器
- 固态硬盘（SSD）：Flash 芯片组成

## I/O 接口

### I/O 接口的功能

- 主机和外设的通信联络控制
- 地址译码和设备选择
- 数据缓冲
- 信号格式转换
- 传送控制命令和状态信息

### I/O 接口的类型

- 按数据传送方式：并行接口（8255）、串行接口（8251）
- 按控制方式：程序查询接口、中断接口（8259）、DMA 接口（8257）
- 按可编程性：可编程接口（8255、8251）、不可编程接口（8212）
- 按通用性：通用接口、专用接口

### I/O 接口编址

- 统一编址（存储器映射）：I/O 端口和主存统一编址，CPU 用访存指令访问
- 独立编址（I/O 映射）：I/O 端口单独编址，需专用 I/O 指令

## I/O 方式

### 程序查询方式

- CPU 和 I/O 串行工作
- CPU 不断查询 I/O 设备状态（「踏步等待」）
- 简单但 CPU 利用率极低

### 程序中断方式

- CPU 和 I/O 并行工作
- I/O 设备完成操作后向 CPU 发中断请求
- 异常和中断：故障、自陷、终止（内中断）；外部中断（外中断）
- 中断处理流程：中断请求 → 中断判优 → 中断响应 → 中断处理 → 中断返回
- 中断向量：中断服务程序的入口地址
- 中断向量地址：存放中断向量的地址

### DMA 方式

- 直接存储器访问（Direct Memory Access）
- DMA 控制器接管总线，直接在主存和外设间传输数据
- 传送方式：停止 CPU 访存、周期挪用、DMA 与 CPU 交替访存
- 传送过程：预处理 → 数据传送 → 后处理
- 与中断方式区别：DMA 请求总线使用权，中断请求 CPU 处理时间

### 通道方式和处理机方式

- 通道：专用 I/O 处理部件，可执行通道程序
- 处理机：独立于 CPU 的专用处理机
