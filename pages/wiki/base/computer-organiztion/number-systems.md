# 数制与编码 Number Systems

## 进位计数制及其相互转换

- 真值：带正负号的实际数值
- 机器数：数值数据在计算机中的二进制表示形式
- 基数转换：整数部分除基取余，小数部分乘基取整

## BCD 码

- 二进制编码的十进制数，用 4 位二进制表示 1 位十进制

## 字符与字符串编码

- ASCII 码：7 位二进制编码，共 128 个字符
  - 控制字符：0-31
  - 空格 SP：32
  - 可打印字符：32-126（'A'=65，'a'=97）
- 汉字编码：输入码、机内码、字形码

## 校验码

### 奇偶校验码

- 奇校验：整个校验码中「1」的个数为奇数
- 偶校验：整个校验码中「1」的个数为偶数

### 海明校验码 Hamming Code

- 校验位位数条件：$$n + k \le 2^k - 1$$（n 为数据位，k 为校验位）
- 纠错能力：可检测 2 位错，纠正 1 位错

### 循环冗余校验码 CRC

- 利用生成多项式对数据进行模 2 运算得到冗余码
- 具有很强的检错能力
