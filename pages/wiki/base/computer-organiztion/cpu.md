# 中央处理器 CPU

## CPU 的功能

- 指令控制：程序的顺序执行
- 操作控制：产生操作信号送到相应部件
- 时间控制：对各种操作实施时间控制
- 数据加工：算术和逻辑运算
- 中断处理：处理异常和外部中断

## CPU 的基本结构

### 运算器

- ALU：算术逻辑单元（核心）
- 累加寄存器 ACC
- 暂存寄存器
- 通用寄存器组
- 程序状态字寄存器 PSW
- 移位器
- 计数器 CT

### 控制器

- 程序计数器 PC：存放当前指令地址，位数取决于存储器容量
- 指令寄存器 IR：存放当前指令，位数取决于指令字长
- 指令译码器：对操作码译码
- 存储器地址寄存器 MAR
- 存储器数据寄存器 MDR
- 微操作信号发生器

### 寄存器可见性

- 用户可见：PC、通用寄存器组、PSW
- 用户不可见：MAR、MDR、IR

## 指令执行过程

### 指令周期

- CPU 从主存取出并执行一条指令的时间
- 包含：取指周期、间址周期、执行周期、中断周期
- 基本单位：时钟周期

### 数据流

- 取指周期：PC→MAR→M→MDR→IR，PC+1
- 间址周期：Ad(IR)→MAR→M→MDR（取有效地址）
- 执行周期：不同指令数据流不同
- 中断周期：保存断点、形成中断入口地址、硬件关中断

### 指令执行方案

- 单指令周期：所有指令用相同时间完成
- 多指令周期：不同指令用不同时间完成
- 流水线方案：多条指令重叠执行

## 数据通路的功能和基本结构

- 数据在功能部件之间传送的路径
- CPU 内部单总线方式
- CPU 内部三总线方式
- 专用数据通路方式

## 控制器的功能和工作原理

### 硬布线控制器（组合逻辑控制器）

- 速度快，但修改和扩展困难
- 同步控制、异步控制、联合控制
- 设计步骤：列出微操作节拍 → 确定节拍安排 → 设计组合逻辑电路

### 微程序控制器

- 微命令 → 微指令 → 微程序
- 微命令是最小单位（控制信号）
- 速度慢，但修改和扩展容易
- 微指令格式：操作控制字段 + 下地址字段
- 编码方式：直接编码、字段直接编码、字段间接编码
