## Hardentools

Hardentools（Windows 软件）提供比 Windows 的默认设置更加激进的安全性调整，进一步减少系统的攻击面。仅面向普通个人用户，不适用于企业环境。不建议禁用 Windows Defender 实时保护功能，否则部分调整将无法生效。如果你需要使用 Windows Powershell 或命令提示符，则不要勾选“Disable Powershell”和“Disable cmd.exe”这两个选项。

## CompactGUI

CompactGUI（Windows 软件）

通过调用 Windows 10+ 内置的 compact.exe，对任意用户文件或文件夹进行无损压缩（不改变文件哈希，不会影响相关软件正常运行）。

设备 CPU 性能不高的话不建议使用。
