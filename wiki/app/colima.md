## 安装

```sh
# Homebrew
brew install colima

# MacPorts
sudo port install colima

# Nix
nix-env -iA nixpkgs.colima

# Mise
mise use -g colima@latest
```

## 用法

```sh
# 启动
brew services start colima
```
