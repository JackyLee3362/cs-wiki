## 通用

- [prettier](docs/app/devtools/prettier.md) - 支持 JS/TS/JSON/CSS/Markdown 等多种语言的「有主张」的格式化工具。

## Python

- [black](docs/app/devtools/black.md) - Python 官方推荐的「无争议」代码格式化工具。

## Java

- [google-java-format](docs/app/devtools/google-java-format.md) - Google 风格的 Java 代码格式化工具。

## Go

- [gofmt](docs/app/devtools/gofmt.md) - Go 官方自带的代码格式化工具，风格统一到社区标准。
