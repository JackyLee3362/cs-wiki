软件、命令行工具与平台按主要用途分组；同一主题目录内同时收录具体条目与 `compare-*` 选型对比。数据库服务与数据库客户端分别归档，避免将 MySQL 和 Navicat 混在一类。

## 主题目录

- ai：AI 工具与智能体
- android：Android 工具
- backup：备份与同步
- blog：博客与建站
- browser：浏览器与书签
- business：业务系统
- communication：通信与邮件
- container：容器（Docker、Podman）
- database：MySQL、PostgreSQL、MariaDB 等数据库，以及服务端选型对比
- database-cli：Navicat、DBeaver 等客户端和数据库管理工具
- devtools：开发工具链
- files：文件管理、压缩与文档处理
- finance：财务记账
- game：游戏开发
- git：Git 与代码托管
- health：运动与健康记录
- information：资讯与信息服务
- linux：Linux
- macos：macOS
- media：影音、图像与照片管理
- network：网络、代理与内网穿透
- note：笔记与知识管理
- obsidian：Obsidian
- ops：运维与监控
- productivity：任务、日历与工作流
- project：项目管理
- science：科学计算与可视化
- security：密码、认证与安全工具
- server：应用服务与消息基础设施
- system：操作系统与输入法
- terminal：终端、shell 与常用命令
- virtualization：虚拟化
- vscode：VS Code
- windows：Windows

常用工具可从[总览](docs/index.md)的安装与入门清单直达。
