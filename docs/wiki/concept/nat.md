## 定义

NAT（Network Address Translation，网络地址转换）是一种在局域网和互联网之间转换 IP 地址的技术，允许多台内网主机共享一个或少量公网 IP 地址访问互联网。

## 工作原理

- 内网主机使用私有 IP 地址（如 192.168.x.x）
- NAT 路由器将私有 IP 转换为公网 IP
- 通过端口号区分不同内网主机的连接
- NAT 工作在传输层（因为要查看端口号）

## 私有 IP 地址范围

| 类型 | 范围                          |
| :--- | :---------------------------- |
| A 类 | 10.0.0.0 ~ 10.255.255.255     |
| B 类 | 172.16.0.0 ~ 172.31.255.255   |
| C 类 | 192.168.0.0 ~ 192.168.255.255 |

## 类型

- **静态 NAT**：一对一固定映射
- **动态 NAT**：从地址池中动态分配
- **NAPT/PAT**：端口地址转换，多对一映射（最常用）
