## 定义

后退 N 帧协议（Go-Back-N, GBN）允许发送方连续发送多个帧而无需等待确认，若某帧出错或丢失，则从该帧起所有已发送但未确认的帧全部重传。

## 特点

- 发送窗口 $W \le 2^n - 1$，接收窗口 = 1
- 接收方只能按序接收帧
- 累积确认：ACK n 表示序号 n 及之前的所有帧都已正确接收
- 超时后重传所有已发送未确认的帧

## 优缺点

- 优点：信道利用率比停等协议高
- 缺点：出错后重传量大，不适合出错率高的信道
