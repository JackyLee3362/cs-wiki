## 定义

OSPF（Open Shortest Path First，开放最短路径优先）是一种基于链路状态的内部网关协议（IGP）。

## 特点

- 向自治系统中所有路由器发送信息，使用泛洪法（RIP 仅向相邻路由器发送）
- 是网络层协议，直接使用 IP 数据报传送（不使用 UDP/TCP）
- 支持分层区域划分，减少协议流量
- 收敛速度快

## 五种分组类型

1. **问候分组 Hello**：发现和维护邻站可达性
2. **数据库描述分组 DD**：向邻站发送链路状态数据库摘要
3. **链路状态请求分组 LSR**：请求特定链路状态信息
4. **链路状态更新分组 LSU**：泛洪法发送完整链路状态信息
5. **链路状态确认分组 LSAck**：对链路状态更新的确认

## 与 RIP 对比

| 特性     | RIP            | OSPF       |
| -------- | -------------- | ---------- |
| 算法     | 距离向量       | 链路状态   |
| 交换对象 | 相邻路由器     | 所有路由器 |
| 协议层次 | 应用层         | 网络层     |
| 传输协议 | UDP            | IP         |
| 收敛速度 | 慢             | 快         |
| 网络规模 | 小（最大15跳） | 大         |
