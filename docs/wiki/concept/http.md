## 定义

HTTP（HyperText Transfer Protocol，超文本传输协议）是应用层协议，用于在 Web 浏览器和服务器之间传输超文本数据，是万维网（WWW）的基础。

## 特点

- 无状态：服务器不保存客户端状态
- 无连接：每次请求/响应后断开连接（HTTP/1.0）
- 灵活：可传输任意类型的数据
- 简单快速：客户端向服务器请求服务时，只需传送请求方法和路径

## 方法

| 方法   | 说明             |
| :----- | :--------------- |
| GET    | 请求获取资源     |
| POST   | 提交数据给服务器 |
| PUT    | 上传资源         |
| DELETE | 删除资源         |
| HEAD   | 获取响应头       |
| PATCH  | 局部更新资源     |

## 状态码

| 类别 | 说明                                    |
| :--- | :-------------------------------------- |
| 1xx  | 信息性状态码                            |
| 2xx  | 成功（200 OK）                          |
| 3xx  | 重定向（301, 302）                      |
| 4xx  | 客户端错误（404 Not Found）             |
| 5xx  | 服务器错误（500 Internal Server Error） |

## HTTP/1.1 vs HTTP/2 vs HTTP/3

- **HTTP/1.1**：持久连接、管道化、分块传输
- **HTTP/2**：二进制分帧、多路复用、头部压缩、服务器推送
- **HTTP/3**：基于 QUIC（UDP），减少连接建立延迟
