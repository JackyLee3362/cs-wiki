## 一位全加器

- 和表达式：$$S_i = A_i \bigoplus B_i \bigoplus C_{i-1}$$
- 进位表达式：$$C_i = A_iB_i + (A_i \bigoplus B_i)C_{i-1}$$
- 全加器（FA）是加法器的基本单元

## 串行加法器

- 器件少、成本低，但运算速度慢
- 一次只处理一位的加法

## 并行加法器

- 由多个全加器组成，同时处理多位数据
- 进位传递：$$C_i = G_i + P_iC_{i-1}$$（G 为进位生成，P 为进位传递）
- 串行进位方式（行波进位）：逐级传递，速度慢
- 并行进位方式（先行进位/超前进位）
  - 单级先行进位（CLA）：4 位先行进位电路
  - 多级先行进位（BCLA）：成组先行进位电路，兼顾速度与复杂度

## ALU 的功能和结构

- 带标志加法器：产生进位、溢出、零、符号等标志位
- 算术逻辑单元（ALU）：支持算术运算和逻辑运算
- 补码加减运算部件：统一加减法运算，简化硬件设计
- ALU 是运算器的核心部件
