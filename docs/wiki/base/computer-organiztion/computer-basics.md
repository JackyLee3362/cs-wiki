## 计算机发展历程

- 四代计算机
  - 第一代：电子管时代
  - 第二代：晶体管时代
  - 第三代：中小规模集成电路时代
  - 第四代：超大规模集成电路时代
- 摩尔定律：集成电路上可容纳的晶体管数目，约每隔 18 个月便会增加一倍，性能也将提升一倍
- 固件：将程序固定在 ROM 中组成的部件

## 计算机系统的组成

- 硬件系统：计算机的实体（主机、外设等）
- 软件系统：由具有各类特殊功能的信息（程序）组成

## 计算机硬件的基本组成

- 冯诺依曼机 = 运算器 + 存储器 + 控制器 + 输入设备 + 输出设备
- 哈佛结构：将程序指令存储和数据存储分开的存储器结构
- 运算器核心：ALU（算术逻辑单元），含 ACC、MQ、X 等寄存器
- 控制器核心：PC（程序计数器）、IR（指令寄存器）、CU（控制单元）

## 计算机软件分类

- 系统软件：操作系统、数据库管理系统、语言处理程序等
- 应用软件
- 三个级别的语言：机器语言、汇编语言、高级语言

## 计算机工作过程

- 源程序到可执行文件：预处理 → 编译 → 汇编 → 链接
- 指令执行三步骤：取指令（PC→MAR→M→MDR→IR）→ 分析指令（OP(IR)→CU）→ 执行指令（Ad(IR)→MAR→M→MDR→ACC）
- 多级层次结构：微程序机器层 → 传统机器语言层 → 操作系统层 → 汇编语言层 → 高级语言层

## 计算机性能指标

- 机器字长：一般等于内部寄存器的大小
- 主存容量：存储字数 × 字长
- 运算速度
  - CPU 时钟周期 = 1 / 主频
  - CPI：执行一条指令所需的时钟周期数
  - CPU 执行时间 =（指令条数 × CPI）/ 主频
  - MIPS：每秒执行多少百万条指令
  - MFLOPS：每秒执行多少百万次浮点运算
- 吞吐量与响应时间
