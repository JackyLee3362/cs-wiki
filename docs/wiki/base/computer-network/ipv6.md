## IPv6 主要特点

| 特性     | 说明                                             |
| -------- | ------------------------------------------------ |
| 地址长度 | 128 bit（16 Byte），解决 IPv4 地址耗尽问题       |
| 分片策略 | 一般不允许分片（源节点可以分片，路由器不能分片） |
| 首部长度 | 必须是 8B 的整数倍（IPv4 是 4B）                 |
| 首部格式 | 简化，固定 40B 基本首部 + 扩展首部               |
| 安全性   | 支持 IPSec 认证和加密                            |
| 即插即用 | 支持无状态地址自动配置（SLAAC）                  |
| 扩展性   | 扩展首部链式结构，灵活添加新功能                 |

### 与 IPv4 的关键区别

- IPv4 首部长度可变（20B-60B），IPv6 固定 40B 基本首部
- IPv4 首部校验和逐跳计算，IPv6 无首部校验和（由上层协议保证）
- IPv4 用 ARP 解析 MAC 地址，IPv6 用邻居发现协议（NDP）
- IPv4 广播地址，IPv6 取消了广播（由组播替代）

## IPv6 地址

### 地址类型

| 类型           | 说明                       |
| -------------- | -------------------------- |
| 单播 Unicast   | 一对一通信                 |
| 组播 Multicast | 一对多通信                 |
| 任播 Anycast   | 一对最近的一组中的一个通信 |

注：IPv6 取消了 IPv4 的广播地址，由组播替代。

### 地址表示

- 8 组 16 位十六进制数，每组 4 个十六进制数字
- 例如：`2001:0db8:85a3:0000:0000:8a2e:0370:7334`
- 压缩表示：连续 0 可用 `::` 代替（只能使用一次）

## IPv4 到 IPv6 的过渡策略

| 策略     | 说明                                             |
| -------- | ------------------------------------------------ |
| 双协议栈 | 节点同时运行 IPv4 和 IPv6 两个协议栈             |
| 隧道协议 | 将 IPv6 数据报封装在 IPv4 数据报中穿越 IPv4 网络 |
