MariaDB 是 MySQL 的开源分支，常用 SQL 与 MySQL 相近，版本和认证机制存在差异。

客户端使用 `mariadb`；密码管理见 [MySQL 密码恢复](docs/wiki/app/mysql/password-recovery.md)。
