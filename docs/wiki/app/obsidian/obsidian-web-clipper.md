Obsidian 官方推出的浏览器剪藏扩展，可将网页内容一键保存到笔记库。

## 特点

- 官方出品，与 Obsidian 深度集成
- 支持自定义剪藏模板
- 可提取网页正文、选中内容或整个页面
- 支持保存网页元数据（标题、URL、时间等）
- 可配合 Local REST API 实现无官方同步的剪藏
