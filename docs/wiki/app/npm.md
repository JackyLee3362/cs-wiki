## 特点

- Node.js 官方默认的包管理器
- 全球最大的 JavaScript 软件包仓库
- 支持语义化版本控制
- npm scripts 可替代简单的构建工具
- 随 Node.js 安装，开箱即用

## 常用命令

```sh
npm install 包名       # 安装依赖
npm install -g 包名    # 全局安装
npm uninstall 包名     # 卸载依赖
npm update             # 更新依赖
npm run 脚本名         # 执行 package.json 中的脚本
```
