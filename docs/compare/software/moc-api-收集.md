## API 工具

### Postman

Postman → Hoppscotch / Bruno / Apidog（自托管模式）

- Postman 是 API 领域的主要产品，但它也是以云为中心的，对于基本测试来说可能有些过度。
- Hoppscotch 是一款简洁的基于浏览器的 API 客户端，您可以自行托管。
  它支持 REST、GraphQL、WebSocket 甚至 MQTT，非常适合快速请求或测试，无需安装繁重的桌面软件。
- Bruno 将 API 集合存储为纯文本文件，方便进行版本控制。它能够完美集成到 Git 工作流程中，并专注于离线优先的开发。
- Apidog 提供了更完善的 API 管理套件，包含测试、模拟和文档功能。您可以为需要企业级功能的团队提供私有托管服务，而无需担心 SaaS 锁定。
