## MaxTo

对于高效率办公，土豪的方式很简单：砸钱。就像很多大佬都配备双显示器一样，双屏协作，效率可以提高69%。而MaxTo就是一款让电脑分屏的软件，不用烧钱买双显示器，你也能双（多）屏协作。
