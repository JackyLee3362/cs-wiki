> 媒体播放器与查看器覆盖视频播放、图片浏览、文件快速预览等场景，追求轻量、开源、格式兼容性。

## 工具概览

| 工具 | 类型 | 开源 | 价格 | 平台 | 核心特点 |
| :--- | :--- | :--: | :--- | :--- | :--- |
| [mpv](https://mpv.io/) | 视频播放器 | ✅ | 免费 | 全平台 | 极简跨平台，比 VLC 更纯粹，命令行与脚本扩展性强 |
| [VLC](https://www.videolan.org/vlc/) | 视频播放器 | ✅ | 免费 | 全平台 | 播放一切格式，生态最成熟，支持流媒体与转码 |
| [Honeyview](https://www.bandisoft.com/honeyview/) | 图片查看器 | ❌ | 免费 | Windows | 轻量快速，支持多种格式，但已停止更新 |
| [QuickLook](https://github.com/QL-Win/QuickLook) | 文件快速预览 | ✅ | 免费 | Windows | 空格键预览文档/PDF/视频/图片/压缩包等 |
| [Snipaste](https://www.snipaste.com/) | 截图+贴图 | ❌ | 免费 | 全平台 | 截图后贴图到桌面，参考对比神器 |
| [IrfanView](https://www.irfanview.com/) | 图片查看器 | ❌ | 免费 | Windows | 老牌轻量看图，插件丰富，启动极快 |
| [qView](https://interversehq.com/qview/) | 图片查看器 | ✅ | 免费 | 全平台 | 极简设计，零边框，跨平台 |

## 按场景推荐

### 视频播放

追求极简与纯粹播放体验，推荐 **mpv**（无多余 UI，配置灵活，适合进阶用户）。如果需要开箱即用、格式兼容性最强且带有完整 GUI 的播放器，推荐 **VLC**（支持几乎所有编码和流媒体协议）。

### 图片浏览

Windows 下需要快速查看图片，**Honeyview** 曾是首选（轻量、快速），但已停止更新；长期替代可考虑 **IrfanView**（功能更丰富）或 **qView**（开源跨平台，极简零边框）。

### 文件快速预览

Windows 用户强烈建议安装 **QuickLook**，移植了 macOS 的空格预览体验，支持 Office、PDF、视频、图片、压缩包、电子书等格式，显著提升文件浏览效率。
