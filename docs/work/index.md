记录工作中遇到的具体问题，整理背景、排查过程、解决方法与验证结果，方便后续查阅和复用。

## 常见面试知识点

结合工作场景整理原理、常见追问和易错点，也作为日常排查的复习入口。

- [MySQL](docs/work/mysql.md)：索引、事务隔离、锁、日志、慢查询与主从延迟。
- [Redis](docs/work/redis.md)：数据类型、缓存一致性、持久化、分布式锁与集群。
- [微服务](docs/work/microservices.md)：服务拆分、幂等、一致性、消息与故障治理。

## 记录内容

- **问题背景**：业务场景、运行环境、问题现象和影响范围。
- **排查过程**：复现步骤、日志与证据、尝试过的方法和原因分析。
- **解决方法**：具体操作、代码或配置调整，以及验证结果。
- **经验复盘**：踩坑原因、预防措施和后续改进。

后续按项目或主题在 `docs/work/` 下添加 Markdown 文档，侧边栏会自动收录。
